五款成熟产品的移动端结构拆解 —— 以及哪几条该搬进你的 Trilium 客户端

分析对象：有道云笔记 · 苹果备忘录 · Obsidian · 思源笔记 · flomo　｜　2026-10-17

01先说结论

你的 App 现在最大问题不是「少了功能」，而是信息骨架和手势路径不对。成熟产品在手机上做对了四件事，而你现在四条都缺：

① 首屏必须「一眼看到内容」——不是看到入口、图标、加载圈。
② 层级浏览要「就地展开」——不是跳进跳出、反复返回。
③ 记录入口要「零摩擦」——打开就能写，不选分类。
④ 所有高频操作要「单手可达」——拇指区域，不是左上角。

下面逐个拆，最后给你一份按优先级排的改造清单。

思源笔记 文档树 · 和你最近似 它的差评 = 你的避坑清单

功能和你说最像（文档树 + 块编辑），但移动端被用户骂得很具体。这些差评几乎就是你现在 App 的问题复刻。

  • 「感觉手机端就是电脑版简单换了布局，完全沿用桌面操作逻辑」 ← 你之前直接加载 Trilium 网页编辑器，一模一样的问题
  • 「图标小小的，非常容易误触，单手几乎没法操作」 ← 点击区域要 ≥44pt
  • 「打开下一个文档要在屏幕左上角点两次，每次都要把手机放桌上操作」 ← 高频操作必须在拇指区
  • 「文档树/书签/搜索/最近浏览这四个核心功能，都要 2-3 步操作」 ← 核心浏览入口必须一步直达
  • 「UI 像老软件，放大图标、加圆角、加点过渡动画，整体就有活力了」
  • 块状内容管理、离线优先、大文档流式加载（技术底子好）
用户的改进建议（可直接抄）：文档树图标放右边好单手够到；左右滑切文档树/大纲；下滑上滑切换上下篇；常用按键放屏幕下方；主界面放大图标入口（笔记本/书签/最近）。

04你的 App：现状诊断

对照截图和代码，问题按「用户能感知到的程度」排序：

1. 列表行信息太薄——只有「标题 + 时间」。你的库里全是「密码」「网线线序」「车辆继承过户」这种短标题，光看标题根本分不清内容。有道云和备忘录都在列表里给一行正文摘要。
2. 视图切换器在顶部，单手够不到——「最近 / 目录」分段控件放在标题下方（我上一版为了绕开 iOS 15 的 toolbar bug 挪上去的），但它在拇指区之外。思源被骂的第一条就是这个。
3. 树和列表是「二选一」——切到目录就看不到最近，切回最近就用不了树。有道云用抽屉共存（左滑出树、主屏留列表），Obsidian 用侧栏，都比二选一顺。
4. 导航层级不透明——点进笔记后，不清楚自己在树的哪一支，回上一级要按返回。面包屑只有树里有，阅读页没有。
5. 视觉缺少「呼吸感」——列表行、分段控件、按钮都偏紧凑；圆角、间距、层级阴影缺少系统性的节奏。

05改造清单（按性价比排序）

① 列表行加正文摘要 P0 · 最划算

列表行改成三行结构：标题（15-16pt 中等） / 正文摘要一行（13pt 灰） / 时间（11pt 更浅）。摘要来源：读过的笔记用缓存内容，没读过的首次不摘要（不强求）。

参考：备忘录、有道云。效果：密码 下面能看到「微信/支付宝/银行卡…」，一眼分清。

② 视图切换改到底部（拇指区） P0

把「最近 / 目录」从顶部横条挪到底部——可以做成悬浮胶囊（左下角），或者底部细条工具区。iOS 15 上safeAreaInset(edge: .bottom)稳定可用。

同时把右上角「文件夹 / 齿轮」也下移，或干脆收进底部工具区，让右上角彻底清空。

③ 树与列表共存：左滑出目录 P1 · 结构升级

学 Obsidian / 有道云：主界面永远是列表，从屏幕左边缘右滑唤出目录树面板（覆盖式抽屉，占屏 80%）。这样既能一键看最近，又能随时浏览树，不用二选一。

实现要点：HStack + offset 动画，或 ZStack 叠层 + DragGesture。注意别和列表横向滑动冲突（只在左边缘 20pt 内响应）。

④ 阅读页加「位置感」+ 底部操作条 P1

阅读页顶部显示面包屑（我的笔记 / 汽车保养相关），点击可跳同级；底部放操作条：编辑、上/下篇（学思源用户建议的上下滑切换）。

⑤ 视觉节奏：统一间距与圆角 P2 · 感知提升

列表行垂直内边距 12-14pt（现在偏紧）；卡片圆角 12pt；分段控件换成胶囊型并加轻微阴影；图标统一 20-22pt，点击热区 ≥44pt（思源被骂「图标小易误触」）。

⑥ 树节点增加「展开状态持久化」 P2

记住上次展开到哪一层（UserDefaults 存已展开 noteId 集合），下次进来直接还原——深目录用户最需要这个。

⑦ 速记升级为「打开即写」 P2 · 学 flomo

现在要点右下「＋」弹窗再写。可以做到：从桌面小组件 / 长按图标直接进输入态，写完自动落收件箱，全程 1-2 步。

06别学的地方

  • 别学 flomo 去掉层级——你的库是树状知识体系，强项不能丢
  • 别学 Obsidian 的双侧栏——两个手势方向在手机上极易误触（思源用户也在骂左右滑）
  • 别学思源把桌面逻辑搬到手机——这是它被骂最多的一条，也是你之前网页编辑器的老毛病
  • 别在列表里塞满缩略图——有道云自己也说过，图片/附件会让列表节奏凌乱
